kigit Status

How to use

In order to check the current status of kicad files, simply type kigit status.

There is also a quickstatus command that simply shows whether there are current, uncommited changes or not, with kigit quick-status.

@app.command()
def quick_status():
    """Show a quick message of the status of your KiCad files in your Repository"""
    logger.info("starting \"quick_status\"-command")
    gitmanager = GitManager(cwd)
    status = gitmanager.get_change_status()
    print("There are current changes" if status else "No changes at the moment")
